## Доработка индивидуального проекта

В приложениях созданы каталоги `templates` с пространствами имён:

```text
homepage/templates/homepage/
    base.html, index.html, 404.html
    includes/navigation.html
courses/templates/courses/
    course_list.html, course_detail.html
    includes/course_card.html
materials/templates/materials/
    material_list.html, material_detail.html
    includes/material_card.html, includes/status_badge.html
homepage/static/
    css/style.css
    js/main.js
```

`base.html` содержит HTML-каркас, Bootstrap, навигацию и подвал. Блоки `title`
и `content` переопределяются дочерними шаблонами через `{% extends %}`.
Навигация, карточки и бейдж статуса подключаются через `{% include %}`,
что устраняет повторение разметки.

Функция `page()` удалена. Представления вызывают `render(request,
template_name, context)`. На этапе ПР6 данные загружались из JSON функциями
ПР3 и передавались в контексте под ключами `courses`, `course`, `materials`,
`material`. Например, `course_list()` передавала список объектов, а шаблон
выводил их названия через `{{ course.name }}`.

Конструкции `{% for %}` перебирают курсы, материалы и студентов; `{% empty %}`
выводит сообщение для пустых списков. Условия `{% if %}` выбирают текст и цвет
статусов активности и публикации. Фильтры `length` и `truncatechars` выводят
количество объектов и сокращённые названия.

Имена маршрутов объединены пространствами `homepage`, `courses`, `materials`.
Ссылки строятся через `{% url 'courses:detail' course.id %}` и аналогичные
конструкции. Это позволяет менять адреса в `urls.py` без правки HTML.

Через `{% load static %}` и `{% static %}` подключены `style.css` и `main.js`.
CSS задаёт фон, оформление карточек и их состояние при наведении. JavaScript
после загрузки документа обновляет год в подвале. Страница 404 также наследует
общий каркас и возвращается со статусом 404. README дополнен описанием шаблонов.
