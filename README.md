# Система учёта учебных материалов

Консольное приложение для хранения и организации материалов учебных курсов и
проверки доступа студентов к ним. Версия проекта соответствует практической
работе № 2.

## Возможности

- просмотр курсов и учебных материалов;
- поиск материалов по части названия;
- сортировка материалов по году и названию;
- проверка доступа с учётом курса студента, активности курса, публикации и
  минимального года обучения;
- добавление и удаление материалов;
- статистика по публикациям и категориям;
- загрузка и сохранение данных в JSON;
- безопасный ввод и обработка ошибок файлов.

## Структура проекта

- `main.py` — точка запуска, консольное меню и вывод данных;
- `access.py` — уровни доступа и правила проверки материалов;
- `courses.py` — поиск и обработка курсов;
- `materials.py` — добавление, удаление, поиск, сортировка и статистика;
- `storage.py` — чтение и запись JSON с обработкой ошибок;
- `utils.py` — функции безопасного пользовательского ввода;
- `data/courses.json` — исходные данные курсов;
- `data/materials.json` — исходные данные материалов;
- `tests/` — автоматизированные тесты;
- `pr-lanets.md` — краткий отчёт по ПР2.

## Формат данных

Курс хранится как JSON-объект:

```json
{
  "id": 1,
  "name": "Технологии разработки приложений на базе фреймворков",
  "is_active": true
}
```

Учебный материал содержит связь с курсом и правила доступа:

```json
{
  "id": 1,
  "course_id": 1,
  "title": "Основы Python",
  "category": "practice",
  "publication_year": 2026,
  "is_published": true,
  "min_study_year": 1
}
```

Поддерживаемые категории: `lecture`, `practice`, `exam`.

## Требования и установка

Требуется Python 3.9 или новее. Основное приложение использует только
стандартную библиотеку. Инструменты разработки устанавливаются командой:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Запуск

```bash
python3 main.py
```

После запуска отображается меню:

```text
1. Показать курсы
2. Показать материалы
3. Найти материал
4. Проверить доступ студента
5. Добавить материал
6. Удалить материал
7. Показать статистику
0. Выход
```

Изменения материалов сразу сохраняются в `data/materials.json`.

## Проверка проекта

Запуск тестов:

```bash
pytest
```

Проверка оформления:

```bash
flake8
```

Тесты проверяют правила доступа, добавление, удаление, поиск, сортировку,
статистику и JSON-хранилище.

## Развитие сценария ПР1

Функции ПР1 `get_access_level()`, `get_category_name()`,
`check_material_access()` и `get_material_age()` сохранены и распределены по
профильным модулям. Одиночные значения курса и материала заменены коллекциями,
которые загружаются из JSON. Проверка доступа теперь работает для любого
материала из набора данных.
