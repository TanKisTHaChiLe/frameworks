# Система учёта учебных материалов

## Назначение

Приложение предназначено для хранения и организации учебных материалов по
курсам, а также для проверки возможности предоставления материала конкретному
студенту. Система помогает собрать лекции, практические задания и материалы для
подготовки к экзаменам в одном месте.

## Целевая аудитория

Студенты, преподаватели и сотрудники образовательных организаций. Студенты
получают доступ к материалам своих курсов, а преподаватели смогут публиковать и
систематизировать учебный контент.

## Предметная область

Предметная область проекта — организация учебного процесса и электронных
образовательных материалов. Каждый материал относится к определённому курсу и
категории. Студенты получают доступ к материалам с учётом года обучения, статуса
курса и статуса публикации материала.

## Основные сущности

- **Курс** — учебная дисциплина, содержащая материалы.
- **Материал** — лекция, практическая работа или материал для подготовки к экзамену.
- **Студент** — пользователь, которому предоставляется доступ к учебным материалам.
- **Категория** — тип учебного материала.

## Основные функции

- определение уровня доступа студента по году обучения;
- определение названия категории материала по её коду;
- проверка доступности материала студенту;
- вычисление возраста учебного материала;
- вывод сведений о курсе, материале, категории и результате проверки доступа.

## Реализованный сценарий ПР1

Пользователь вводит имя студента и год обучения. Программа показывает сведения
об учебном материале и проверяет доступ к нему. Решение учитывает корректность
года обучения, активность курса, публикацию материала и ограничения категории.

В программе использованы простые типы данных, операции, преобразование строки в
число, условные конструкции, функции и импорт стандартного модуля `datetime`.

## Запуск проекта

Требуется Python 3. Запуск из корневого каталога:

```bash
python3 main.py
```

Пример вводимых данных:

```text
Введите имя студента: Анна
Введите год обучения (от 1 до 6): 2
```

## Отладка

Для демонстрации отладки можно поставить точку останова на строке, где вызывается
`check_material_access`, запустить программу в режиме Debug и проверить значения
`study_year`, `is_course_active`, `is_material_published` и `material_category`.

Для поиска учебной ошибки временно измените значение `is_material_published` с
`True` на `False`. С помощью пошагового выполнения определите, почему доступ был
отклонён, после чего верните правильное значение.

- подключить базу данных и Django ORM;
- реализовать создание, просмотр, изменение и удаление данных;

- разработать REST API;
- добавить автоматизированные тесты;
- контейнеризировать приложение с помощью Docker;
- настроить CI/CD.
