## Анализ предметной области и доработка проекта

В ПР2 курс и материал были словарями, а сведения о студенте существовали только
как отдельные переменные в момент проверки доступа. Для ПР3 выделены классы:

| Класс | Основные атрибуты | Поведение |
| --- | --- | --- |
| `Course` | идентификатор, название, активность | строковое представление, преобразование в JSON |
| `Material` | идентификатор, объект курса, название, категория, год публикации, публикация, минимальный год обучения | проверка доступа, возраст, строковое представление, преобразование в JSON |
| `Student` | имя, год обучения | уровень доступа, проверка материала, строковое представление |

В каждом классе реализованы `__init__` и `__str__`. Связь
`Material.course` даёт материалу доступ к текущему состоянию курса.
`Student.check_access(material)` использует метод материала, который учитывает
год обучения студента, статус курса и ограничения публикации. Уровень доступа
оформлен свойством `Student.access_level`; создание объектов из JSON выполняют
методы класса `from_dict`.

Функции ПР2 по обработке коллекций адаптированы к спискам объектов. Сохранены
поиск и сортировка, добавление и удаление, статистика, консольное меню и
обработка ошибок ввода. Загрузка JSON создаёт объекты и связывает материал с
существующим курсом по `course_id`. Сохранение преобразует объекты обратно в
совместимый с ПР2 формат JSON. Некорректная ссылка на курс вызывает
`DataFileError`.

Тесты адаптированы к объектам и дополнены проверкой взаимодействия классов,
строкового представления, восстановления связей после загрузки JSON и ошибки
при отсутствующем курсе. Документация `README.md` обновлена.

## Результат и вывод

Индивидуальный проект переведён на объектную модель без изменения формата
исходных данных и набора команд меню. Поведение, относящееся к отдельному
материалу или студенту, выражено методами; операции над коллекциями остались
функциями. Проверки проекта: 17 тестов `pytest` проходят, `flake8` не
обнаруживает замечаний. Для полного закрытия учебного задания студенту
остаётся самостоятельно пройти и подтвердить материалы Яндекс Практикума.
