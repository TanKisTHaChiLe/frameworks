# Система учёта учебных материалов

Сквозной проект по дисциплине «Технологии разработки приложений на базе
фреймворков». Программа хранит курсы, их материалы и студентов; позволяет
искать материалы, проверять доступ, добавлять записи и смотреть статистику.
После ПР6 проект также предоставляет веб-интерфейс Django на шаблонах. Данные
пока загружаются из JSON, поэтому консольное приложение ПР3 продолжает работать.

## Объектная модель

| Класс | Атрибуты | Основные методы |
| --- | --- | --- |
| `Course` | `id`, `name`, `is_active`, `materials`, `students` | `add_material`, `remove_material`, `find_materials`, `add_student`, `find_students`, `from_dict`, `to_dict` |
| `Material` | `id`, `course`, `title`, `category`, `publication_year`, `is_published`, `min_study_year` | `__str__`, `access_result`, `age`, `from_dict`, `to_dict` |
| `Student` | `id`, `course`, `name`, `study_year` | `__str__`, `access_level`, `check_access`, `from_dict`, `to_dict` |
| `Category` | `LECTURE`, `PRACTICE`, `EXAM` | `from_code`, `label`, `__str__` |

`Course` — главная сущность проекта: это предметное направление, например
«Машинное обучение» или «Программирование на Python». Курс хранит свои
материалы и студентов, управляя связями с ними. Числовой `id` нужен только
для хранения и выбора записи в меню; он не означает год обучения.

`Material.course` хранит ссылку на объект `Course`. При проверке доступа
`Student.check_access()` передаёт свой год обучения методу материала. Материал
проверяет состояние связанного курса, публикацию, категорию и минимальный год
обучения. При сохранении JSON содержит только `course_id`; при загрузке
идентификатор снова связывается с соответствующим объектом курса.
`Student.course` указывает на курс, на который записан студент.
`Student.study_year` — отдельное число от 1 до 6: год обучения студента,
который используется для проверки доступа к материалу. Студент может открыть
только материалы своего курса.
`Material.category` хранит значение перечисления `Category`. Оно задаёт
допустимые категории и их русские названия; в JSON сохраняется прежний
строковый код категории.

Главное меню работает со списком курсов, а общие списки материалов и студентов
при необходимости собирает из них. Функции сортировки и статистики работают с
коллекцией материалов. Правила конкретного материала находятся в его методах.
`main.py` отвечает за меню и ввод.

## Файлы

- `models/courses.py` — класс `Course`, его материалы и студенты;
- `models/categories.py` — перечисление `Category` и названия категорий;
- `models/materials.py` — класс `Material`, сортировка и статистика;
- `models/access.py` — класс `Student` и общие правила доступа;
- `storage.py` — преобразование JSON в объекты и обратно, обработка ошибок;
- `main.py` — консольный интерфейс;
- `utils.py` — безопасный ввод;
- `data/` — JSON-файлы курсов, материалов и студентов;
- `tests/` — тесты;
- `pr3-lanets.md` — отчёт по ПР3.

## Запуск и проверка

Требуется Python 3.9 или новее. Приложение использует стандартную библиотеку.

```bash
python3 main.py
```

Веб-интерфейс:

```bash
python3 manage.py runserver
```

Основные страницы: `/`, `/courses/`, `/courses/<id>/`, `/materials/` и
`/materials/<id>/`. Маршруты распределены между приложениями `homepage`,
`courses` и `materials`; неизвестные адреса и идентификаторы получают HTTP 404.
Страницы наследуют общий `base.html`, повторяемые карточки и навигация подключены
через `{% include %}`, ссылки строятся через `{% url %}`. Собственные CSS и
JavaScript находятся в `homepage/static/`.

Для тестов и проверки стиля:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
pytest -v
flake8 .
```

Меню позволяет показать курсы, материалы и студентов, найти материал,
проверить доступ выбранного студента, добавить или удалить материал, добавить
студента и посмотреть статистику. Изменения материалов и студентов сразу
записываются в соответствующие JSON-файлы.

## Формат хранения

Курс хранится в `data/courses.json` с полями `id`, `name`, `is_active`.
Поле `name` содержит название направления; списки материалов и студентов
собираются по ссылкам `course_id` из двух других файлов.
Материал хранится в `data/materials.json` с полями `id`, `course_id`,
`title`, `category`, `publication_year`, `is_published` и
`min_study_year`. Категории: `lecture`, `practice`, `exam`.
Студент хранится в `data/students.json` с полями `id`, `course_id`,
`name`, `study_year`.

При повреждённом JSON, неверной структуре записи или ссылке на отсутствующий
курс выводится понятная ошибка данных.
